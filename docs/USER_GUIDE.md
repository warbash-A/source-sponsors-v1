# SponsorScout User Guide

## Quick Start

1. **Enter event details** - Name, type, industry, location
2. **Choose event count** - 3 recommended (faster), 5 for more results
3. **Find events** - Search conference websites OR paste specific URLs
4. **Select events** - Choose 1-3 events with sponsor counts shown
5. **Extract sponsors** - Get sponsor list with tiers and websites

## Best Practices

### ✅ For Best Results

- **Use specific event URLs** - Paste direct links to events you know
- **Limit to 3 events** - Faster results, less likely to timeout
- **Look for sponsor counts** - Events showing "X sponsors" will have results
- **Try major conferences** - Larger events usually list sponsors clearly

### ⚠️ When Things Go Slow

- **Takes 1-2 minutes** - Processing 3 events is normal
- **Some events return 0 sponsors** - Not all events list sponsors publicly
- **Manual URLs work best** - Skip discovery, go straight to known events

## Troubleshooting

### "No sponsors found"
- Event may not have a public sponsors page
- Try a different event or paste a direct URL
- Major conferences work better than small meetups

### "Request timed out"
- Reduce event count to 3
- Try manual URL input instead of search
- Wait a moment and try again

### "No events found"
- Use broader keywords ("tech conference" vs specific names)
- Try pasting a specific event URL
- Check spelling and location

## Limitations

- Discovery: ~30-60 seconds per search
- Sponsor extraction: ~20-40 seconds per event
- Max 5 events per search (3 recommended)
- Some events may not list sponsors publicly
- Conference sites work better than directories
